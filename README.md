## Website Description
This website presents a traditional Pakistani Dhaba and its food offerings. It was extended from the original Lab 11 project into a multi-page website.

## Website Pages
1. **Home (index.html):** Introduction, popular food items, and Order Now button.
2. **Menu (menu.html):** Food items and their prices.
3. **Gallery (gallery.html):** Gallery displaying Dhaba food images.
